System Architecture: Prototype vs Production Scale

Honest technical breakdown of client-side SIH demonstration versus enterprise law-enforcement deployment

Current SIH Prototype

In-Browser Standalone Evaluation Platform

Zero cloud reliance; runs 100% locally and on static GitHub Pages.

Graph Engine & Visualization
Hardware-accelerated HTML5 Canvas with custom force-directed simulation, spatial culling, and camera transformation matrix.
Network Centrality Algorithms
Brandes unweighted betweenness centrality (O(V·E)), normalized degree centrality, and deterministic community detection implemented in JavaScript.
Evidence Ingestion & Parsing
RFC 4180 PapaParse CSV engine for CDRs and banking ledgers; regex deterministic entity extraction; client-side SHA-256 evidence hashing.
Chain of Custody Audit Log
Append-only SHA-256 cryptographically chained audit log via Web Crypto API stored in browser LocalStorage with on-demand verification.
Legal Compliance
Generates draft investigative leads dossiers explicitly citing Section 63 of the Bharatiya Sakshya Adhiniyam, 2023 (BSA 2023).
Production Target Architecture

Enterprise Law-Enforcement Sovereign Cloud / On-Prem

Designed for high-throughput multi-agency criminal intelligence cells.

Enterprise Graph Database
Neo4j Enterprise Cluster with Graph Data Science (GDS) library executing PageRank, Louvain modularity, and GraphSAGE embeddings.
Multilingual Deep NLP & OCR
Fine-tuned IndicBERT & Legal-BERT NER pipelines, Tesseract OCR for scanned FIRs, and Whisper AI for multilingual audio intercept transcription.
Streaming Evidence Ingestion
Apache Kafka distributed streaming bus for real-time telecom tower dumps, CCTNS FIR event feeds, and FIU financial transaction monitoring.
Permissioned Consortium Blockchain
Hyperledger Fabric permissioned ledger across State Police, CBI, ED, and FIU nodes for unalterable multi-agency evidentiary audit trails.
Security & Air-Gapped Deployment
Kubernetes microservices on air-gapped sovereign VPC, RBAC clearance tiers, and HSM-backed digital signature certificates.
